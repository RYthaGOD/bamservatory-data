## Reproduce

Run from the repository root:

```sh
node test/compare-september15.mjs
node compare.mjs --day 2026-09-15
node compare.mjs --day 2026-09-15 --b vantage/sin/raw --strict
```

The final command must fail. The regression test pins all three archive hashes,
the discrepant endpoints, the validator's return and normal/strict behavior.

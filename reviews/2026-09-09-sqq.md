# September 9 SQQ comparison finding

Reviewed September 11, 2026 against the immutable daily archives. The repeated
CI failures all reported Amsterdam at **2026-09-09T17:53**: an extra
`sqq-mainnet-bam-1-tee` node. The comparator was right to report it. This was
not a new outage on each subsequent CI run.

## Why the check failed, and the resolution

Amsterdam's intermediate 17-node set does not appear in the primary's
17:52–17:54 window: the primary goes from 16 to 19. The relabelling exception
requires identical header stake, which this pair does not have. Only the node
set check fails; stake and validator counts fit the existing three-minute
envelope and tolerances.

`REVIEWED.tsv` now explains this one vantage and minute. The finding remains
visible, and `--strict` still fails it. Raw files and comparison tolerances are
unchanged. The new regression test checks the archived amounts, endpoint lag,
subsequent recovery, and both normal and strict comparison outcomes.

The primary header/node discrepancies in this interval are below the existing
0.5% publication exclusion threshold, so these captures remain in the series.
That is the documented treatment of small endpoint skew, not evidence of exact
atomic agreement. No historical metric has been silently rewritten.

## Monitoring corrections found during review

The hourly freshness-only run used the same workflow badge as full archive
verification. It could replace a red badge with green while all archive jobs
were skipped. Hourly monitoring now has a separate workflow and badge; every
`verify` run executes the full validation suite.

The comparison also returned success for absent/non-overlapping/unreadable
data, and discarded findings after the first ten per day before applying
reviews. These paths now fail explicitly and have regression tests. Freshness
checks validate the publication, capture and verification timestamps, reject
invalid/future dates, and retain bounded retries for transient HTTP failures.
Full verification also recomputes the published rows from archived evidence.
